# sidge-lunch

Where can I get lunch on Sidgwick site, and what is it today?

> **This is an unofficial, independent project.** It is not affiliated with, endorsed by, or run by the
> University of Cambridge, any of its faculties or departments, or any college or vendor listed. Menus are
> collected automatically from the vendors' public web pages and may be incomplete, wrong or out of date.
> Always check with the vendor, especially about allergens and dietary requirements.

Vibe coded using Claude.

A static site with two views of the same data:

- **Map**: pick your site and building (Sidgwick, Downing, Cambridge West, a college, ...) and see the places
  to eat within a chosen walk. Click one for today's menu.
- **Dashboard**: today's lunch at every place in range, filterable by dietary label, allergen, price, type
  (college, University, commercial) and whether a menu is available.

Menus are scraped only for a handful of places that publish them as plain web pages. Everything else
(colleges, University cafés, and commercial cafés, pubs and restaurants from OpenStreetMap) is shown with its
opening hours and a link.

## How it works

```
GitHub Actions (cron)                        GitHub Pages
┌───────────────────────────────┐            ┌──────────────────────┐
│ scraper/  fetch each menu page │  commits   │ web/ (Vite + Leaflet)│
│ → vendor adapter → common JSON ├──────────► │ reads data/*.json    │
│ → data/menus.json if changed   │  deploys   │                      │
└───────────────────────────────┘            └──────────────────────┘
```

| Path | What it is |
| --- | --- |
| `data/vendors.json` | Hand-curated places: everything scraped, University Catering cafés, checked details. Edited by hand; overrides `places.json`. |
| `data/places.json` | Generated from OpenStreetMap: colleges, University cafés, commercial cafés, pubs and restaurants. Don't edit. |
| `data/sites.json` | Generated from OpenStreetMap: University sites and colleges, with their buildings, for the "where am I" picker. Don't edit. |
| `data/menus.json` | Generated by the scraper. Don't edit. |
| `data/walking/<site>.json` | Generated walking routes from each building to places nearby. Don't edit. |
| `scraper/osm/` | The OpenStreetMap query and its latest result. |
| `scraper/sidge_lunch/places.py` | Builds `sites.json` and `places.json` from the OpenStreetMap snapshot. |
| `scraper/sidge_lunch/schema.py` | The common menu format every adapter produces. |
| `scraper/sidge_lunch/adapters/` | One HTML parser per vendor. |
| `scraper/sidge_lunch/run.py` | Fetches every vendor, updates `menus.json` only when something changed. |
| `scraper/sidge_lunch/walking.py` | Computes walking routes via OSRM (OpenStreetMap), one file per site. |
| `web/` | The site. |

### Workflows

- **Scrape menus** (`scrape.yml`) runs every 30 minutes through the morning and every 3 hours otherwise. If
  `menus.json` changed it commits and redeploys. Menu pages don't say when they change, so the scraper
  compares a hash of the parsed menu instead.
- **OpenStreetMap snapshot** (`osm.yml`) runs one Overpass query when `scraper/osm/cambridge.overpassql`
  changes or on demand, rebuilds `sites.json` and `places.json`, then runs walking times.
- **Walking times** (`walking.yml`) recomputes routes when sites or places change, or on demand. It only
  routes places within about 1.6 km of each site and pauses between requests. Until it has run, the site
  shows straight-line estimates marked "≈".
- **Deploy site** (`deploy.yml`) builds `web/` with `data/` and publishes to GitHub Pages.
- **CI** (`ci.yml`) runs the scraper and web tests.

### Menu data

Each vendor in `menus.json` has a `status`:

- `ok`: parsed successfully. `updated_at` is when the menu content last changed.
- `error`: the latest fetch or parse failed. The last good menu is kept and the site says it may be stale.
- `unsupported`: no adapter written yet. The site links to the vendor's page.

Menus are only scraped from pages anyone can open: never from intranets or Raven-protected pages, and never
past a bot check (Queens', Wolfson and Pembroke use one) or robots.txt (Downing's Kafoodle menu disallows it). PDF, Word, image and Canva menus are
linked, not read.

Who can eat at each college (`scraper/sidge_lunch/college_access.json`) is paraphrased from Silas S. Brown's
[Eating at other Cambridge colleges](https://ssb22.user.srcf.net/buttery.html), with the year each entry was
last checked.

Dietary labels are only recorded when the vendor publishes them. Adapters must never guess them from dish
names. Items without a published price show "price not listed".

## Adding a vendor

Most places come from OpenStreetMap automatically. To scrape one, or to correct its details, add it to
`data/vendors.json` with its `osm` id (the generated copy is then dropped):

1. Add it to `data/vendors.json` (id, name, type, menu URL, coordinates). If its menu can't be scraped, set
   `"link_only": true` and stop here: the site will just link to the vendor's page.
2. Save a copy of its menu page to `scraper/tests/fixtures/<id>.html`.
3. Write `scraper/sidge_lunch/adapters/<id>.py` with `parse(html, today) -> list[Day]`, register it in
   `adapters/__init__.py`, and add a test against the fixture.
4. Merge to `main`. Walking times are recomputed automatically.

To refresh OpenStreetMap data, run the **OpenStreetMap snapshot** workflow from the Actions tab.

## Development

```sh
# scraper
cd scraper
python -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/pytest
.venv/bin/python -m sidge_lunch.run --only selwyn   # updates ../data/menus.json

# site
cd web
npm install
npm run dev      # serves ../data; SIDGE_DATA_DIR=/path/to/sample npm run dev to use other data
npm test
```

## One-time setup

In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

## Etiquette

The scraper identifies itself with a User-Agent linking to this repository, respects `robots.txt`, and
fetches each page at most every 30 minutes. If you run a listed vendor and would like it removed or changed,
please open an issue.
